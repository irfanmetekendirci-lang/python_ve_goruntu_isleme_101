VisionDraw: Havada Çizim Uygulaması — Açıklama Notları

Dersin Amacı Bu eğitim; katılımcıların değişkenler, listeler, döngüler ve fonksiyonlar gibi temel Python kavramlarını somut bir projede birleştirmesini hedefler. Bilgisayarlı görü (OpenCV) ve derin öğrenme (MediaPipe) kullanarak işaret parmağıyla ekranda havaya çizim yapmayı adım adım öğreneceğiz.

1. Kullanılan Kütüphaneler ve Rolleri

  • OpenCV (cv2): Bilgisayarlı görü kütüphanesidir. Kamerayı açar, pencereleri yönetir, pikselleri okur ve ekrana geometrik şekiller (daire, çizgi, metin) çizer.
  • MediaPipe: Google tarafından geliştirilen derin öğrenme kütüphanesidir. Kamera karesindeki eli milisaniyeler içinde tespit eder ve eklemlerin koordinatlarını üretir.
  • NumPy: Üzerine çizim yapacağımız boş dijital tuvali (canvas) temsil etmek için kullanılan matris kütüphanesidir.
# Kurulum Komutu
pip install opencv-python mediapipe numpy

2. Zihinde Canlandırma: 4 Temel Benzetme

  1. Flipbook (Çevirmeli Defter Mantığı): Bilgisayar için video yoktur; ardışık fotoğraflar (frame) vardır. while True döngüsü bir defteri çevirir gibi saniyede ~30 kareyi peş peşe işler.
  2. Ters Çevrilmiş Y Ekseni (Piksel Dünyası): Bilgisayar ekranlarında sol üst köşe (0,0) noktasıdır. Sağa gittikçe X artar, aşağı indikçe Y büyür.
  3. 21 Raptiye (Landmarks): MediaPipe ele 21 adet sanal raptiye iliştirir. Çizim için sadece 8 (işaret parmağı ucu) ve durum kontrolleri için 6 (orta eklem) ile 12 (orta parmak ucu) noktalarını kullanırız.
  4. Asetat Kâğıdı (Canvas Mantığı): Doğrudan kamera karesine çizersek el hareket ettikçe çizgi kaybolur. Kameranın önüne şeffaf bir kâğıt koyduğumuzu varsayarız; çizimleri buna yapar, sonra kamerayla birleştiririz.

3. Satır Satır Adım Analizi

Adım 1: Kütüphaneler ve Model Kurulumu

import cv2
import mediapipe as mp
import numpy as np

mp_hands = mp.solutions.hands
hands = mp_hands.Hands(max_num_hands=1, min_detection_confidence=0.7)
mp_draw = mp.solutions.drawing_utils
  • mp_hands, hands, mp_draw birer değişkendir.
  • Hands(...) ilk harfi büyük olduğu için bir sınıftır (class); çalışmaya hazır bir el tespit asistanı üretip hands değişkenine bağlarız.
  • max_num_hands=1: Ekranda birden fazla el olsa bile sadece tek bir ele odaklanmasını sağlar.
  • min_detection_confidence=0.7: Modelin %70 emin olmadan koordinat üretmesini engelleyerek ekrandaki titremeleri ve hatalı algılamaları önler.

Adım 2: Kamera ve Tuval Değişkenleri

cap = cv2.VideoCapture(0)
canvas = None
prev_x, prev_y = 0, 0
draw_color = (0, 0, 255)
  • cap = cv2.VideoCapture(0): Bilgisayarın varsayılan dahili kamerasını başlatır.
  • canvas = None: Tuvali başlangıçta boş tanımlarız; ilk kamera karesi geldiğinde kameranın gerçek çözünürlüğüne göre boyutlandırılır.
  • prev_x, prev_y = 0, 0: Kalemin "az önce nerede olduğunu" aklımızda tutan hafıza değişkenleridir.
  • draw_color = (0, 0, 255): OpenCV renkleri BGR (Blue, Green, Red) tuttuğu için bu kod saf kırmızı renktir.

Adım 3: Sonsuz Video Döngüsü ve Ön İşlemler

while True:

  • cv2.flip(frame, 1): Görüntüyü yatayda ters çevirir (ayna etkisi). Elimizi sağa götürdüğümüzde ekrandaki çizgi de sağa gitsin diye şarttır.
  • np.zeros((h, w, 3), dtype=np.uint8): Kamerayla birebir aynı boyutta, tüm pikselleri sıfır (tamamen siyah) boş bir tuval oluşturur.
  • cv2.cvtColor(..., cv2.COLOR_BGR2RGB): OpenCV BGR okurken MediaPipe RGB bekler; bu tercüme yapılıp yapay zekaya verilir.

  • cv2.waitKey(1) & 0xFF: Pencerenin donmaması için 1 ms bekler ve basılan tuşu okur.
  • ord('c'): C tuşuna basıldığında tuvali yeniden simsiyah yaparak ekranı temizler (Clear).
  • ord('q'): Q tuşuna basıldığında döngüyü kırar (Quit).

4. Eksiksiz Proje Kodu (`vision_draw.py`)

import cv2
import mediapipe as mp
import numpy as np

mp_hands = mp.solutions.hands
mp_draw = mp.solutions.drawing_utils
hands = mp_hands.Hands(max_num_hands=1, min_detection_confidence=0.7)

cap = cv2.VideoCapture(0)
canvas = None
prev_x, prev_y = 0, 0
draw_color = (0, 0, 255)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    frame = cv2.flip(frame, 1)
    h, w, c = frame.shape

    if canvas is None:
        canvas = np.zeros((h, w, 3), dtype=np.uint8)

    rgb_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    results = hands.process(rgb_frame)

    if results.multi_hand_landmarks:
        for hand_landmarks in results.multi_hand_landmarks:
            lm = hand_landmarks.landmark

            ix, iy = int(lm[8].x * w), int(lm[8].y * h)
            mx, my = int(lm[12].x * w), int(lm[12].y * h)

            index_open = lm[8].y < lm[6].y
            middle_open = lm[12].y < lm[10].y

            if index_open and not middle_open:
                cv2.circle(frame, (ix, iy), 8, draw_color, cv2.FILLED)
                if prev_x == 0 and prev_y == 0:
                    prev_x, prev_y = ix, iy
                cv2.line(canvas, (prev_x, prev_y), (ix, iy), draw_color, 5)
                prev_x, prev_y = ix, iy

            elif index_open and middle_open:
                prev_x, prev_y = 0, 0
                cv2.circle(frame, (ix, iy), 12, (255, 0, 0), 2)
            else:
                prev_x, prev_y = 0, 0

            mp_draw.draw_landmarks(frame, hand_landmarks, mp_hands.HAND_CONNECTIONS)
    else:
        prev_x, prev_y = 0, 0

    combined_frame = cv2.addWeighted(frame, 1.0, canvas, 0.7, 0)
    cv2.putText(combined_frame, "Temizle: C | Cikis: Q", (15, 35),
                cv2.FONT_HERSHEY_SIMPLEX, 0.7, (255, 255, 255), 2)
    cv2.imshow("VisionDraw", combined_frame)

    key = cv2.waitKey(1) & 0xFF
    if key == ord('q'):
        break
    elif key == ord('c'):
        canvas = np.zeros((h, w, 3), dtype=np.uint8)

cap.release()
cv2.destroyAllWindows()

5. Hızlı Sorun Giderme Rehberi

Problem Olası Neden Hızlı Çözüm
Kamera Açılmıyor Kamera indeksi 0 değildir veya arkada başka uygulama kullanıyordur. VideoCapture(1) deneyin, diğer kamera programlarını kapatın.
El Titriyor / Çizgi Kopuyor Işık yetersizdir veya ten rengi arka planla karışıyordur. Işığı artırın ya da min_detection_confidence=0.5 yapın.
Çizim Ters Yöne Gidiyor Ayna etkisi atlanmıştır. cv2.flip(frame, 1) satırını kontrol edin.
Pencere Donuyor waitKey(1) eksiktir. Döngü içinde cv2.waitKey(1) olduğunu doğrulayın.
